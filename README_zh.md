# MT-Memory 实验材料

安装、运行和目录说明见[英文README](README.md)。本仓库提供三套UCI源数据及处理后数组、28个实验入口和论文结果记录。

建议依次运行 `verify`、`make test`、`smoke`、`tables` 和 `figures`。图表重建使用保存的结果，不代表重新测量性能。需要重新执行实验时，用 `list` 查看名称，再运行 `run 实验名称 --output 新目录`。

v0.3.1源码包与v0.3.0完整原始记录包配套使用；后者内容和摘要未变，下载链接见英文README。导入后执行 `verify --full` 和 `audit-raw`，可检查完整记录及逐请求指标。

科学实现、实验驱动及全部实验记录保留原样。部分驱动沿用历史目录名，以匹配协议中的来源哈希；公开运行入口使用实验名称。高负载失败、年龄匹配平局和先验变化下的反转结果均保留。
