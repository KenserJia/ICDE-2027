# Body displays

`python reproduce.py tables --output runs/tables` generates Tables I–VI and RQ3 paired results from complete entity/run records and checks manuscript-rounded values. `python reproduce.py figures --output runs/figures` regenerates Figures 1–4 through the isolated scientific plotting drivers. The source logic is in `src/mtmemory_artifact/analysis.py` and the registered `repro/*/figures.py` drivers. Recorded vectors/previews are in `figures/recorded`.

TableI: common-panel history allocation. TableII: full joint-budget recent versus histogram. TableIII: history-only polynomial/L2. TableIV: validation-selected kernel/history parameters. TableV: complete joint recovery cases. TableVI: separate short/wide three-way cost controls. Figure1: joint architecture. Figure2: controlled per-budget triptychs. Figure3: same-layout calibration and symmetric selection. Figure4: joint throughput, fusion opportunity, locality and query tail. Full mapping is in `evidence/PAPER_MAP.json`.
