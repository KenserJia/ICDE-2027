# RQ3

- `rq3-calibration`: Distance/dwell calibration and held-out confirmation. Run from the repository root with `python reproduce.py run rq3-calibration --output runs/rq3-calibration`.
- `rq3-symmetric`: Independent validation layout tuning for both policies. Run from the repository root with `python reproduce.py run rq3-symmetric --output runs/rq3-symmetric`.
- `rq3-kernel`: Fixed-layout bandwidth and query-history sensitivity. Run from the repository root with `python reproduce.py run rq3-kernel --output runs/rq3-kernel`.
