# RQ2

- `rq2-controlled`: Phase-controlled reach / exactness / error grid. Run from the repository root with `python reproduce.py run rq2-controlled --output runs/rq2-controlled`.
- `rq2-model-ablation`: Polynomial/L2 comparison and coarse/overlay/reservation ablations. Run from the repository root with `python reproduce.py run rq2-model-ablation --output runs/rq2-model-ablation`.
- `rq2-fixed-width`: Complete prior fixed-width supplemental curves. Run from the repository root with `python reproduce.py run rq2-fixed-width --output runs/rq2-fixed-width`.
- `rq2-triptych-source`: Complete fixed-demand supplemental precision/reach grid. Run from the repository root with `python reproduce.py run rq2-triptych-source --output runs/rq2-triptych-source`.
- `joint-quality`: Validation-frozen joint recent/histogram quality and snapshots. Run from the repository root with `python reproduce.py run joint-quality --output runs/joint-quality`.
