# ICDE2027 supplemental-material audit

Official policy checked2026-11-10: https://icde2027.github.io/submission-guidelines.html (Supplemental Material) and https://icde2027.github.io/cf-research-papers.html . ICDE expects code, data and implementation artifacts supporting reported results; availability is evaluated. EAB papers must provide all artifacts needed to reproduce results. Material must use an openly accessible standard service such as public GitHub. The policy does not prescribe a particular ZIP layout or require the MIT license; those are this project's engineering and reuse choices. Single-blind review allows author names. A supplemental artifact is not a manuscript appendix; the manuscript must remain self-contained and satisfy its own page rules.

| Check | Local status / action |
| --- | --- |
| Code and dependencies | Modular original core, portable artifact layer, exact dependency pins and optional Java/SQL dependencies documented |
| Data and access | All3UCI source ZIPs and processed arrays included; DOIs, creators, transforms and licenses documented |
| Supporting results | Current and prior relevant records indexed; 7,131 binary members supplied as separate checksum-verified archive |
| Experiment-to-claim map | Six current tables, two figures and28protocols mapped in `docs/EXPERIMENTS.md` |
| Repeatability | Isolated fresh outputs; fast smoke, data rebuild, tests and record-based display reconstruction distinguished from fresh benchmarks |
| Negative results | High-load failures, same-allocation ties, prior reversals and certificate costs preserved |
| Licenses | Original codeMIT; data/derived recordsCC BY4.0; ScottyApache2.0, original notices intact |
| Public access | **Pending author upload** of both dated assets and anonymous-download verification; local readiness alone does not satisfy online availability |
| Version identification | Local source/data manifests, raw manifest and current manuscript hashes; actual public commit/tag/URLs to be recorded after upload |
| AI disclosure | This revision uses OpenAI Codex for packaging/wrapper/documentation changes. It does not fabricate data or timing results. The manuscript's existing AI disclosure must cover the work actually used in the submission; this package does not edit that disclosure |

The local validation report specifies executed checks and unexecuted full studies. This audit is not an ICDE artifact badge, a legal opinion, or a claim of acceptance. Submission-system fields and final public access remain the author's responsibility.
